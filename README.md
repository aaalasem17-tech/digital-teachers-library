# مكتبة المعلم الرقمية — Digital Teacher's Library (DTL)

Desktop tool for Jordanian teachers: marks registers (side + final), school certificates, the yearly marks table (الملحفة), the daily attendance register, prep books, content analysis and semester plans — plus a content library of 1,592 files (grades 4–12) and NCCD textbook viewing links.

**This repository is the update + distribution channel.** The app checks `manifest.json` here for new versions (paste its raw URL once into the app's «التحديثات» service) and each release carries the full package as a `.zip` asset.

## Install

1. Download the latest release `.zip` from [Releases](https://github.com/aaalasem17-tech/digital-teachers-library/releases).
2. Extract it to a folder (e.g. Desktop).
3. Double-click `مكتبة المعلم الرقمية.bat` — the app opens in your browser and works offline. Your data stays on your device (browser storage).

## Updates

When a new version is published here, the app announces it with a download button (internet needed only for the check). Extract the new zip over the same folder; your saved data is preserved.
